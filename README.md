# RS CAD 3D — Downloads

3D CAD for **architecture/building** and **mechanical part** design, for Windows.

## Download
➡️ **[Latest release](https://github.com/aribspeat-Rawahi/RS-CAD-3D-Releases/releases/latest)** — download `RS-CAD-3D-Setup-<version>.exe` and run it.

- Windows 10 / 11, 64-bit
- The installer isn't code-signed yet: if Windows SmartScreen says "Windows protected your PC",
  click **More info → Run anyway**.

## Features
- Primitives, sketch-and-extrude, walls, non-destructive booleans (union / subtract / intersect)
- Command line with typed coordinates, grid snap and object snap (endpoint, midpoint, centre, intersection, nearest)
- Move / copy / mirror by points, rectangular and polar arrays
- Top / Front / Side / Iso views, orthographic projection, measure and dimension tools
- Layers (show/hide, lock), units mm / cm / m
- Save projects (`.rscad`); export STL, OBJ and 2D DXF drawings
